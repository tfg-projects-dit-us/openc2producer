Perfil Threat Hunting

Guía para entender los comandos y sus objetivos.

Referencia OASIS

Guía basada en Threat Hunting AP 1.0, borrador CSD02 (21 de febrero de 2024).

Documento completo de OASIS. Este resumen no sustituye la especificación.

Cómo se forma un comando

  • action: qué se solicita; query consulta información e investigate solicita una investigación.
  • target: sobre qué se actúa.
  • args: parámetros de la petición, cuando corresponda.
  • th: identifica los elementos propios de Threat Hunting.

Qué buscamos con cada operación

AcciónObjetivoPropósito
queryfeaturesDescubrir capacidades; pairs devuelve las parejas acción/objetivo.
queryth.huntflowsConocer los procedimientos de investigación disponibles.
queryth.datasourcesIdentificar fuentes de datos para investigar.
investigateth.huntSolicitar una investigación mediante un huntflow seleccionado.

Ejemplo: descubrir capacidades

{
  "action": "query",
  "target": {
    "features": ["pairs"]
  }
}

En los objetivos específicos, th agrupa el objetivo: target.th.hunt identifica el huntflow. Los argumentos de investigación se sitúan en args.th.huntargs; pueden incluir cadenas, datos tipados, rangos temporales o fuentes.

La idea es descubrir primero capacidades, procedimientos y datos, y después preparar una investigación con sus argumentos. La respuesta permite comprobar el estado y consultar los resultados.
